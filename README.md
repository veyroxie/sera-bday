#  Seraphina Birthday Website  
*A soft, flirty, red-themed birthday surprise.*

This is a custom one-page website I built as a birthday gift for **Seraphina**
The site is designed to feel romantic, elegant, and a bit flirty

It includes:

##  Features
-  **Full red-themed aesthetic**  
  Soft gradients, glowing accents, and floating hearts.

-  **Embedded Spotify track**  
  The page features this song:  
  https://open.spotify.com/track/1cQ3LIkZE68pMSnPhZWXLu  
  It’s the main “read this while listening” vibe.

-  **Hidden love note**  
  Clicking the "Click for cringe" button reveals a soft message.

-  **Wifey-coded writing**  
  Text throughout the page is personalised for Seraphina.

-  **Animated floating hearts**  
  Gentle visual effect to make the page feel alive.

-  **Responsive layout**  
  Looks good on desktop and mobile without breaking.

##  Project Structure
├── index.html # Main page (with personalised birthday message)
├── styles.css # Styling, color palette, animations
└── README.md # You're reading this


##  How to Run
1. Download the project files.
2. Keep **index.html** and **styles.css** in the same folder.
3. Open **index.html** in any browser (Chrome, Edge, Safari, etc.)
4. Enjoy the surprise page — preferably with Seraphina beside you 😉

##  Customisation
Want to tweak it?
- Update any text inside `index.html`
- Change the colors in `styles.css` under `:root`
- Replace the Spotify link with another track
- Add photos, animations, or additional sections
